# Exemples

Quatre clonages réels, faits pendant les tests du 10 octobre 2026.

**Le plus récent, avec le parcours actuel** (une seule question, puis les passages à personnaliser) :
[`instagram-outil-gratuit-meme-outil/`](instagram-outil-gratuit-meme-outil/). Un Reel américain de
33 s qui présente un outil gratuit ; le client (le dossier de test de @lemondedumarketing, mot-clé
en message privé avec ManyChat) veut « la même chose en français, même outil, mon mot-clé VIRAL ».
Le fichier `parcours.md` montre la question et le message des passages à personnaliser tels qu'il
les a vus.

Les trois autres ont été faits plus tôt le même jour, pour une cliente fictive : **Claire, coach
nutrition pour femmes actives qui manquent de temps** (mot-clé par défaut : MENU, pas encore de
profil de voix). Leur analyse et leur script restent valables ; leur section « Mes questions »
montre l'ancienne version (2 ou 3 questions avec réponse par défaut), remplacée depuis par la
question unique.

| Dossier | La vidéo d'origine | Ce qu'on y voit |
|---|---|---|
| [`instagram-outil-gratuit-meme-outil/`](instagram-outil-gratuit-meme-outil/) | Reel Instagram d'un créateur américain, 33 s, en anglais | Un outil gratuit présenté avec animations, essai perso, appel « commente un mot » |
| [`instagram-lemondedumarketing/`](instagram-lemondedumarketing/) | Reel Instagram de @lemondedumarketing, 38 s, en français | Un outil gratuit présenté avec démo, appel « commente un mot » |
| [`tiktok-face-camera-podcast/`](tiktok-face-camera-podcast/) | TikTok d'un entrepreneur américain connu, 55 s, en anglais | Un seul conseil, face caméra, presque sans coupe, pas d'appel à l'action |
| [`youtube-short-question-reponse/`](youtube-short-question-reponse/) | YouTube Short d'un investisseur américain connu, 60 s, en anglais | Une question du public, une réponse en image, montage rapide |

Dans chaque dossier :
- `analyse.md` : le script d'origine seconde par seconde, puis pourquoi la vidéo a marché ;
- `script.md` : le script du client, sur la même mécanique, prêt à lire au prompteur.

Le Reel de @lemondedumarketing est publié avec l'accord de son auteur, phrases comprises. Les trois
autres comptes sont anonymisés : leurs phrases sont résumées entre crochets, seule la mécanique
reste. Chez toi, `analyse.md` contient les phrases exactes (et leur traduction) : c'est pour toi,
pour comprendre, jamais pour tourner tel quel.

Les trous entre crochets dans les trois premiers scripts (`[ton aveu]`, `[ta cliente]`…) viennent de
l'ancienne version : aujourd'hui, quand tu réponds « ok », le passage est tourné sans chiffre au
lieu de laisser un trou. Dans tous les cas, le Reel Cloneur™ n'invente jamais un chiffre ni une
histoire à ta place.

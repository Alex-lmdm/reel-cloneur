# Exemples

Trois clonages réels, faits pendant les tests du 10 octobre 2026, pour une cliente fictive :
**Claire, coach nutrition pour femmes actives qui manquent de temps** (mot-clé par défaut : MENU,
pas encore de profil de voix).

| Dossier | La vidéo d'origine | Ce qu'on y voit |
|---|---|---|
| [`instagram-lemondedumarketing/`](instagram-lemondedumarketing/) | Reel Instagram de @lemondedumarketing, 38 s, en français | Un outil gratuit présenté avec démo, appel « commente un mot » |
| [`tiktok-face-camera-podcast/`](tiktok-face-camera-podcast/) | TikTok d'un entrepreneur américain connu, 55 s, en anglais | Un seul conseil, face caméra, presque sans coupe, pas d'appel à l'action |
| [`youtube-short-question-reponse/`](youtube-short-question-reponse/) | YouTube Short d'un investisseur américain connu, 60 s, en anglais | Une question du public, une réponse en image, montage rapide |

Dans chaque dossier :
- `analyse.md` : le script d'origine seconde par seconde, puis pourquoi la vidéo a marché ;
- `script.md` : le script de Claire, sur la même mécanique, prêt à lire au prompteur.

Le Reel de @lemondedumarketing est publié avec l'accord de son auteur, phrases comprises. Les deux
autres comptes sont anonymisés : leurs phrases sont résumées entre crochets, seule la mécanique
reste. Chez toi, `analyse.md` contient les phrases exactes (et leur traduction) : c'est pour toi,
pour comprendre, jamais pour tourner tel quel.

Les trous entre crochets dans les scripts (`[ton aveu]`, `[ta cliente]`…) sont normaux : le Reel
Cloneur™ n'invente jamais un chiffre ni une histoire à ta place.
